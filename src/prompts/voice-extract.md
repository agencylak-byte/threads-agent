## Что вернуть (JSON)
{
  "summary": "2–3 предложения: кто говорит и как это ощущается читателем",
  "toneAxes": {
    "formal": [min, max],   // 0 формальный … 10 свой
    "humor": [min, max],    // 0 серьёзный … 10 с юмором
    "respect": [min, max],  // 0 почтительный … 10 дерзкий
    "emotion": [min, max]   // 0 сухой … 10 эмоциональный
  },
  "habits": ["5–7 речевых привычек, каждая проверяема по текстам"],
  "vocabulary": ["15–20 слов и оборотов, которые автор реально повторяет"],
  "antiVocabulary": ["слова и обороты, которых в текстах демонстративно нет, хотя они типичны для ниши"],
  "openers": ["5–10 типичных зачинов: первые 3–6 слов, как автор начинает"],
  "avgLength": { "post": число_символов, "comment": число_символов, "dm": число_символов },
  "emojiPolicy": "none | rare | moderate",
  "address": "вы | ты | по ситуации",
  "examples": {
    "good": [{ "text": "дословная цитата 1–2 предложения из выборки", "why": "какой приём в ней виден" }],
    "bad": [{ "text": "как НЕ звучал бы автор (придумай контрпример на ту же тему)", "why": "что выдаёт чужой голос" }]
  }
}

## Правила
- Оси — диапазон, не точка: «обычно тут», по 2 края.
- `habits` — про форму: как начинает, как строит абзацы, как заканчивает, что делает с вопросами, как обращается с цифрами.
- `vocabulary` только из текстов. Ничего не добавляй «для красоты».
- `examples.good` — 4–6 дословных цитат из разных текстов. `examples.bad` — 3–4 контрпримера.
- Если комментариев в выборке нет, `avgLength.comment` оцени как треть от поста, `dm` — как половину.
- Не оценивай качество текстов и не давай советов.
