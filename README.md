# Threads-агент LAK

Chrome-расширение (Manifest V3), которое работает в залогиненном Threads Леры: собирает базу постов,
классифицирует авторов на ЛПР, пишет черновики комментариев и постов в её голосе через OpenRouter
(Gemini 3.8 Flash), ведёт очередь одобрения и исполняет одобренные действия с лимитами и стопом по аномалиям.

Спека: `docs/superpowers/specs/2026-09-25-threads-агент-design.md`. План: `docs/superpowers/plans/2026-09-25-threads-агент.md`.

## Установка (unpacked)

```bash
cd threads-agent
npm install
node scripts/make-icons.mjs   # один раз, иконки для манифеста и уведомлений
npm run build                 # → build/chrome-mv3
```

Chrome → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `threads-agent/build/chrome-mv3`.

Для разработки: `npm run dev` (HMR, WXT сам откроет Chrome с расширением).

## Первый запуск

1. Откройте threads.com и войдите в аккаунт. Расширение само определит handle из левого меню.
2. Иконка расширения → боковая панель. «Здоровье» → «Открыть настройки ключа» → вставьте ключ OpenRouter → «Проверить модель».
3. «Голос» → «Изучить мой голос по постам» (соберёт ваши посты и снимет голос) → заполните анкету.
4. «Сбор» → соберите посты по ключевым словам или по аудитории конкурента.
5. «Здоровье» → «Запустить». Раз в минуту движок: классифицирует новые посты → предлагает комментарии → пишет черновики.
6. «Очередь» → одобряйте / правьте / переписывайте / пропускайте. Одобренное отправляется само с человекоподобными паузами и дневными лимитами.

Все действия по умолчанию в режиме «предлагать». Автопилот включается по типам действий в «Лимитах».

## Что делать при паузе по аномалии

Движок сам встаёт на паузу (6 ч → 24 ч → стоп) при «Действие заблокировано», «Повторите попытку позже», капче,
выкидывании на страницу входа. Откройте вкладку threads.com, убедитесь, что всё работает руками, и снимите
паузу в «Здоровье». Если это третья аномалия за сутки — лучше подождать сутки и снизить лимиты.

## Если Threads поменял вёрстку

Все селекторы — в `src/content/selectors.ts`. «Здоровье» → «Проверить сейчас» покажет, какие записи не находят
элементы. Снимите DOM (`tests/fixtures/threads/README.md`), обновите кандидаты в `selectors.ts`, прогоните `npm test`.

## Данные

- Всё локально: IndexedDB `threads-agent` (посты, авторы, действия, метрики, события) и `chrome.storage.local` (настройки, ключ, профиль голоса).
- Наружу уходят только тексты постов в OpenRouter для классификации/черновиков. Экспорт CSV — вкладка «Сбор».
- Синхронизация в Google Sheets и личка — следующий инкремент (схема БД под них уже заложена).

## Структура

```
src/entrypoints/  background.ts (SW) · threads.content.ts · sidepanel/ · options/
src/shared/       типы, контракт сообщений, настройки, константы (лимиты), лог
src/db/           схема IndexedDB, репозитории, CSV
src/llm/          клиент OpenRouter, рендер промтов, разбор JSON, задачи
src/prompts/      classify-lpr · comment-draft · reply-draft · post-draft · voice-extract
src/profile/      профиль голоса, seed (факты, плейбук, ключи, конкуренты), анкета
src/engine/       autonomy · dedupe · planner · scheduler · pacing · dispatcher · anomaly-policy
src/content/      selectors (единственное место) · парсеры · коллектор · действия · аномалии
src/background/   порты, вкладка, джобы, обработчики UI, исполнитель, дневные метрики
src/ui/           панель: очередь, сбор, голос, источники, лимиты, здоровье
```
